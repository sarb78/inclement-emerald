# Inclement Emerald

This is a ROM hack of Pokémon Emerald built using the [**pokeemerald decompilation project**](https://github.com/pret/pokeemerald) and the [**RHH pokeemerald expansion**](https://github.com/rh-hideout/pokeemerald-expansion).

For details, credits, and other projects used, see the hack's [**Poké Community thread**](https://www.pokecommunity.com/showthread.php?t=457039).

## Custom release versions

This fork uses `v1.13.A.B`, based on upstream Inclement Emerald 1.13. `A` counts feature releases and `B` counts bug-fix releases for that feature version. A feature release increments `A` and resets `B` to zero; a bug-fix-only release increments `B`.

The current custom release is **v1.13.1.0**, which adds nearly instant Fast text, move-type effectiveness colors, and guaranteed captures for permitted wild Pokémon throws. The version is displayed in the Save menu.
